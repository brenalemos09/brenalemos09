# Principais projetos
 
### Aeolus — Estação Meteorológica IoT
 
Projeto desenvolvido no contexto do estágio no Vortex Lab. Integra sensores físicos a um ESP32, com comunicação de dados via Wi-Fi/MQTT para um backend com banco de dados e dashboard. Envolve firmware, prototipagem, testes e integração entre hardware e software.
 
**Tecnologias:** ESP32 • C/C++ • PlatformIO • MQTT • Wi-Fi • Node.js • PostgreSQL
 
---
 
### Creator One
 
Plataforma web pessoal, em desenvolvimento, para creators de conteúdo organizarem campanhas, prazos, entregas e informações financeiras.
 
---
 
### BiblioUnifor
 
Aplicativo Android desenvolvido para modernizar a gestão de bibliotecas universitárias, permitindo pesquisa, reservas, empréstimos e gerenciamento administrativo.
 
**Tecnologias:** Kotlin • Android Studio • Firebase
 
---
 
### Sistema Hospitalar em Java
 
Sistema desenvolvido como projeto de Estruturas de Dados utilizando listas, filas e filas de prioridade para gerenciamento de pacientes em ambiente hospitalar.
 
**Tecnologias:** Java
